# Issue tracker: GitHub

Issues 和 specs 使用当前仓库的 GitHub Issues，通过 `gh` CLI 操作。
仓库从 git remote 推断。

遵守上级 AGENTS.md 中的 Issue 写入授权规则。

## Skill 对接

- “publish to the issue tracker”：创建 GitHub issue。
- “fetch the relevant ticket”：读取 issue 及评论、标签。

## Pull requests as a triage surface

**PRs as a request surface: no.**
