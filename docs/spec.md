# 奶龙外观替换：已确认边界

本文记录设计访谈中确认的实现边界。领域术语见 [`CONTEXT.md`](../CONTEXT.md)，宿主事实与证据见 [`外部契约`](external/bangumi.md)。

## 范围与交互

- 三个已匹配域名均在目标范围内；替换所有伪春菜壳的角色外观，包括传统静态壳和 Live2D 壳。
- 跟随宿主的显隐条件，不强制召唤，不在没有伪春菜的页面独立添加奶龙。手动召唤和站内主动召唤同样适用。
- 保留宿主对话气泡、菜单、显示／隐藏入口及其原有行为；不改用户的显示偏好。
- 奶龙仅作装饰，不承接原角色语音、模型动作或触摸交互，不拦截下方页面点击。
- 固定使用 `https://lsky.ry.mk/i/2026/10/03/8a0ced722f2a1.webp`，不提供设置界面或持久化配置。

## 加载、回退与重试

| 状态／事件 | 行为 |
| --- | --- |
| 未加载时进入显示周期 | 立即隐藏原角色外观，再等待奶龙加载；气泡等宿主功能仍保留。 |
| 加载中 | 允许角色外观留白；不设超时，不提前恢复原角色。 |
| 加载中隐藏、再次显示 | 不强制显示、不重复发起请求；仍复用这次在途加载。 |
| 明确加载成功 | 当前应显示时呈现奶龙；宿主隐藏时保持隐藏。后续显示周期复用成功的图片。 |
| 明确加载失败 | 撤销对原角色外观和初始化入口的临时接管，恢复宿主；不得因此召唤已经隐藏的伪春菜。 |
| 失败后进入下一个显示周期 | 再次尝试加载；再次等待时仍立即隐藏原角色。 |

- 失败回退本身不开始新的显示周期，不能触发立即重试循环。
- 主题切换、窗口缩放不单独触发失败后的重试；成功图片也不因此重新请求。
- 请求始终没有成功或明确失败时，允许角色外观一直留白。这是用户选择的等待策略，不用人为超时将其改成回退。

## Live2D 接管与降级

- 尽量接管原站 Live2D 初始化入口，阻止新的模型启动；对已启动模型尽力清理。明确图片加载失败时恢复原初始化入口。
- 不侵入全站 RAF／WebGL；晚接管或原站清理不完整时，不承诺所有残留开销归零。
- 无法安全接管初始化入口时，降级为尝试隐藏已知原角色外观，继续奶龙替换；此时也不保证原模型停止运行。
- 隐藏范围只限角色外观，不以隐藏整个伪春菜容器、气泡或全站 canvas 达成目标。找不到可识别的角色节点时，不扩大范围误伤宿主。

## 尺寸与位置

- 奶龙完整图片外框的高度取当前宿主角色容器的布局外框高度，包含 padding；不追求图片中人物或原模型实际可见区域的逐像素同高。
- 高度随当前壳与原站窄屏规则变化，不统一硬编码；不额外加载原模型或背景图片测量人物高度。
- 图片等比缩放、保留整幅动图及透明留白，不因较宽而降低高度或裁切。
- 图片外框右下角对齐原角色容器右下角，额外宽度向左展开；不增宽宿主正常流容器、不移动气泡。
- 沿用宿主窄屏行为，既不强制显示，也不额外一律隐藏或统一缩小全部壳。

## 人工运行验收

本项目不引入测试体系、构建工具或外部依赖，最终由用户人工运行验收。

- 原站隐藏／召唤及站内主动召唤；气泡、菜单正常交互。
- 加载期间立即隐藏原外观；加载成功、失败及长期未决三种结果。
- 加载中反复隐藏／显示不重复请求、不被迟到结果强制召唤；失败后仅下一显示周期重试，成功后复用。
- 已启动 Live2D、未启动 Live2D及接管入口不可用的降级；图片失败后恢复原外观与初始化。
- 不同传统壳、主题及窄屏切换的高度、右下对齐、透明留白和气泡位置。
- 三域名的真实浏览器行为与视觉效果；当前调查不构成这些运行时场景或性能结果的验证。
